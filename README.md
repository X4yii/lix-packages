# lix-packages

Monorepo oficial de paquetes, bibliotecas y herramientas para LixOS.

## Estructura

- `pkgs/libs/`: Bibliotecas estándar y de sistema (`lix-core`, `lix-c`, `libm`, `lix-zlib`, `pixman`, `freetype`).
- `pkgs/apps/`: Aplicaciones de usuario y recetas de herramientas (`minigzip`, `fontview`, `gcc`, `rustc`).
- `index.toml`: Índice central de paquetes y resolución de dependencias.
